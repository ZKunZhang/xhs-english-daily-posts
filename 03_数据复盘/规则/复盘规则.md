# 复盘规则

当前数据与阶段目标从[数据索引](../README.md)及其指向的正式结论读取。早期固定标题、观看门槛、涨粉目标与投流券规则保存在[6 月历史快照](历史/2026-06_复盘规则.md)，不自动延续到当前阶段。

## 频率与调整

- 每日记录；3 天看趋势并微调选题顺序、难度和封面；7 天评估内容角色与比例。单日波动不直接作为改主线依据。
- 先判断入口曝光、点击、收藏、评论或转粉哪个环节变化，再提出对应调整；记录观察区间、样本量及结论限制。
- 结论使用“继续 / 微调 / 降级 / 暂停”，附证据、下一步与复测时点，不把未验证的归因写成事实。

## 数据口径

保留平台原始文件、导出日期、指标定义和观察窗口；账号趋势与单篇数据分开分析，不强行对齐归因不同的总量。日增、净增和单篇带来涨粉不可混用。

记录曝光、观看、平台封面点击率、收藏和涨粉；互动分析区分用户原始评论、独立评论人数、账号回复与二次对话。派生指标明确分母：

- 收藏率 = 收藏 / 观看。
- 用户评论率 = 用户原始评论数（扣除账号）/ 观看；若称“有效评论率”，沿用阶段结论的有效定义并披露。
- 每千曝光涨粉 = 单篇带来涨粉 / 单篇曝光 × 1000。
- 主页转粉率须有同口径的主页访问与归因涨粉数据；缺字段时标记不可计算。

分母为零、字段缺失或观测时间不同，不填造 0 值或直接排名。平台点击率与自行计算的观看/曝光分列，避免混称。对比 24h、72h 或累计表现时使用一致窗口。

## 落盘与执行

新导出进入 `原始数据/YYYY-MM-DD/`，不覆盖旧快照；正式分析进入 `复盘结论/` 并更新数据索引。排期调整按[工作流](../../04_模板素材/workflow.md)同步。

投流只在本次已授权预算和范围内执行；历史券额与门槛不是当前预算授权。用户只要求分析时交付证据和建议。
