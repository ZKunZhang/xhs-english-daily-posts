# 账号路线｜2026-08-05 起

## 一句话定位

`生活场景里的高频英语短语强对比账号`

不是泛英语知识号，也不是单词辨析号。每篇只解决一组中文意思接近、英语动作或结果不同的高频短语。

## 内容结构

### 70%｜生活短语强对比

优先级最高。要求两边都是完整高频短语，并能在同一场景中画出两个不同动作或结果。

已验证方向：

- `come back / go back`：回到说话者这里 / 回到别处。
- `pick up / drop off`：接到人 / 送下车。
- `get back / give back`：拿回来 / 还回去。

后续题型：开关与调节、继续与切换、推迟与取消、偶遇与发现、用完状态与耗光动作。

### 20%｜完整短语结构辨析

保留 `doing / to do` 等结构题，但首屏必须写完整短语，不能只写 `do / doing`、`sb` 或语法术语。

例：`go on doing / go on to do`，画面先表现“继续原事 / 换下一件”，规则放到第 3 页。

### 10%｜数据重制与合集

只重制旧帖中“曝光低但点击或收藏有潜力”的知识点。必须更换生活场景、标题、例句、自测和整套图片，并记录旧帖数据。普通合集最多每 10 篇出现 1 篇。

## 永久降级

- 单词对单词辨析，不再作为默认日更方向。
- 单短语记忆，如“这个短语一定要记住”。
- 单点纠错、纯拼写差异和只有一个正确答案的错句题。
- `高考 / 专四 / 用法学会了吗` 等考试或课堂包装。
- 需要先理解标题梗、但首屏看不到完整 A/B 的内容。
- 已充分曝光但点赞和收藏承接仍弱的旧知识点。

## 标题与封面

- 标题优先写“同一个中文意思 + 两个具体动作或结果”。
- 封面必须出现完整 A/B 和两个短动作，不堆规则。
- 使用同一人物、物品、机位和光线，只改变一个变量。
- 对立来自动作、方向、位置或时间，不依赖粗撕裂、巨大 `≠` 和高饱和撞色。
- AI 先生成无文字底图，后期固定排字。

## 发布与判断

- 每天 1 篇主线，保持相对稳定的发布时间。
- 单篇基础目标：曝光 `1,500+`、观看 `200+`、点击率 `10%+`。
- 教育内容优先看收藏率；收藏率 `6%+` 说明内容有复用价值。
- 曝光低但点击率 `10%+` 或收藏率 `6%+`：先判断分发和封面，不直接否定知识点。
- 点击率低于 `8%`：优先检查题目门槛、标题和封面对立。
- 获得充分曝光但点赞、收藏仍低：知识价值不足，不重发。
- 每 3 天只调选题顺序和封面；每 7 天才调整内容比例。

## 未来四周目标

1. 连续发布短语对短语，重新强化账号标签。
2. 建立固定视觉系统，让用户在缩略图中认出账号。
3. 每 7 天统计曝光、点击率、收藏率和涨粉，找出最强动作模型。
4. 新选题优先复制“动作差异”，不复制旧标题字面。
