# 发布标题

只是穿好衣服，别随手说 dress up

# 封面文案

都是“穿衣服”

get dressed 穿好

dress up 特意打扮

# 发布正文

孩子还穿着睡衣，你催他“快去穿衣服”；参加婚礼前，你说“今天要打扮一下”。两个场景都和穿衣有关，重点却不一样。

I need to get dressed before breakfast.

我得在早餐前穿好衣服。

We dressed up for the wedding.

我们盛装参加了婚礼。

一句话记住：

get dressed = 把衣服穿好，结束没穿好衣服的状态

dress up = 为聚会、婚礼等场合特意打扮
