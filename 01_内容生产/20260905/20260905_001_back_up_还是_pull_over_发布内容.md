# 发布标题

back up 和 pull over：一个往后倒，一个靠边停

# 封面文案

都是开车动作

back up 往后倒

pull over 靠边停

# 发布正文

停车时听到这两个短语，车走的方向完全不同：一个向后移动，一个向路边移动并停下。

Back up a little. You're too close to the wall.

往后倒一点，你离墙太近了。

Please pull over near the entrance.

请在入口附近靠边停车。

一句话记住：

back up = 让车向后倒

pull over = 把车开到路边停下

先别看答案：

1. There's a space behind you. ___ slowly.
2. I feel sick. Could you ___ for a minute?

评论区只写 1.___ 2.___，看你能不能把车开对方向。
