# 视觉可行性

同一人物、同一卧室衣柜可形成清楚的前后对比：get dressed 是穿好普通日常服装，dress up 是为婚礼换上礼服并增加正式配饰。遮住文字后仍能判断。

# 统一视觉母版

- 版式家族：同一衣柜 / 两种出门准备状态。
- 本篇变化：复古服装目录线稿；正面全身机位；用衣架轨迹串联普通穿衣与正式打扮。
- 画布与安全区：1080×1440，严格 3:4；左右 8%、顶部 7%、底部 10%。
- 字体与色彩：现代黑体和无衬线体，最多两种字重；暖奶油白 #F7F1E7，深咖灰 #3F3A36，A 鼠尾草绿 #8FA99A，B 杏陶色 #D7A184。
- 固定主体：同一位短发女性、同一卧室衣柜、木质穿衣镜和午后侧光。
- 质感：20 世纪中期服装目录式钢笔线描，局部平涂专色，轻微旧纸网点；不是水彩，不是 PPT。
