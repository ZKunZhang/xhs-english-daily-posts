# 发布标题

get dressed 和 dress up：一个穿好衣服，一个特意打扮

# 封面文案

都是“穿衣服”

get dressed 穿好

dress up 特意打扮

# 发布正文

准备出门时，这两个短语都和穿衣有关，但重点不一样：一个是完成穿衣，一个是比平时穿得更讲究。

I need to get dressed before breakfast.

我得在早餐前穿好衣服。

We dressed up for the wedding.

我们盛装参加了婚礼。

一句话记住：

get dressed = 把衣服穿好，结束没穿好衣服的状态

dress up = 为聚会、婚礼等场合特意打扮

先别看答案：

1. The guests are arriving soon. Go and ___ first.
2. Everyone ___ for the costume party last night.

评论区只写 1.___ 2.___，看看你能不能一次全对。
