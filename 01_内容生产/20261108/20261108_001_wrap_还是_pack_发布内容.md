# 发布标题

礼物包上纸，还是装进箱？

# 发布正文

同一个杯子，外面包上纸，和把它装进箱子，都可能被中文叫作“包装”。这组英语关注的动作不同。

Wrap the mug in paper.
用纸把杯子包起来。wrap 侧重材料包在物品外面。

Pack the mug in a box.
把杯子装进箱子。这里的 pack 侧重装入容器，准备存放或运送。

一句话记住：wrap 看包在外面；这组例句里的 pack 看装进容器。

两词有重叠：pack 也能包含加材料保护物品，不只是“塞进箱”。同一个杯子可以先包纸，再装箱；用哪个词，要看你强调包装动作的哪一部分。

再看一组：
Wrap the book in paper.
用纸把书包起来。
Pack the books in a box.
把这些书装进箱子。

先别看答案：选更贴合所描述动作的词。

1. 把纸包在书的外面，强调外层覆盖。
___ the book in paper.（Wrap / Pack）
2. 把衣服装进行李箱，准备出门。
___ the clothes in a suitcase.（Wrap / Pack）

答案和理由在第5页。

用 Wrap ... 或 Pack ... 写一句你准备礼物或行李时会说的话。

每天一组生活里最容易混的英语。
