# 发布标题

触发警报，和警报响了，怎么说？

# 发布正文

开门触发了警报，接着警报响起来。同一件事，可以讲是谁触发，也可以只讲装置响了。

Opening the door set off the alarm.
开门触发了警报。set off 在这里讲造成响起的原因。

The alarm went off.
警报响了。go off 在这里讲装置发出警报声。

一句话记住：本篇 set off the alarm 讲触发；the alarm goes off 讲响起来。

再看一组：
I accidentally set off the alarm.
我不小心触发了警报。
My phone alarm went off at seven.
我的手机闹钟七点响了。

两句可以描述同一事件，不是两种不同的警报。本篇只讲警报或闹钟的用法；set off 和 go off 在其他语境还有别的意思，不能一律套“触发／响”。

先别看答案：

1. 想强调“我不小心触发了警报”：
A. I accidentally set off the alarm.
B. The alarm went off.
2. 只报告“警报响了”，不说明谁触发：
A. I accidentally set off the alarm.
B. The alarm went off.

答案和理由在第5页。

你的闹钟通常几点响？用 My alarm goes off at... 写一句。

每天一组生活英语，分清用法，也保留能换用的边界。
