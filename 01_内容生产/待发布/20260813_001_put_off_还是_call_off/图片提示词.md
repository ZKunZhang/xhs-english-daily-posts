# 图片提示词｜put off / call off

## 新版知识卡规范

- 1080 × 1440、竖版 3:4；2:3 输出须用暖奶油白向左右扩展，禁止裁切。
- 封面上下双卡，顺序固定为：大号短语 → 英文释义 → 中文提示 → 加粗英文例句 → 场景插画。
- 封面指定文字：`put off / 改到以后 / call off / 直接取消`。定义与例句放到第 2 页，不放封面。
- 英文主导、中文辅助；前者鼠尾草绿，后者杏陶色。不要总标题、`≠`、页码或额外文案。
- 图 2—5 分别承担生活例句、视觉规则、自测、答案。图 4 与图 5 必须复用同一场景和裁切，只改变答案、高亮与勾选。
- 清楚表现“移动到新日期”和“直接取消、没有新日期”；使用无文字日历符号，无品牌、会议名称或乱码。

## 执行方式（必须）

第一步只生成 1080 × 1440、竖版 3:4 的无文字插画底图；日历、会议室、门票和球场不得出现任何字母、汉字、数字、品牌或赛事标志。日期用无文字圆点和位置关系表示。第二步用固定模板叠加各页“文字”字段。安全区为左右各约 8%、顶部约 7%、底部约 10%；中文一种现代黑体，英文一种无衬线体；最多两种字重；默认左对齐。

5 页固定同一张日历、会议标记、机位和光线。只改变“标记移动到未来位置 / 标记被划掉且没有新位置”。遮住文字后仍能看懂改期与取消。禁用粗撕裂、巨大 `≠`、高饱和红叉、电影海报光效、贴纸和假手写。

补充规范：严格遵循 `04_模板素材/templates/xhs_visual_system.md`。

统一风格：竖版 3:4，暖奶油白 `#F7F1E7`；`put off` 固定鼠尾草绿 `#8FA99A`，`call off` 固定杏陶色 `#D7A184`；深咖灰正文。低饱和编辑插画、轻微纸张颗粒、固定左对齐网格和圆角场景框。只出现指定文字，不生成日历小字、公司标志或乱码。

## 图 1｜封面
文字：`put off ≠ call off / 一个改到周五 / 一个直接取消`

画面：同一张极简日历左右对照。左侧周一的会议圆点沿鼠尾草绿箭头移到周五；右侧周一的会议圆点被杏陶色斜线划掉，后面没有新日期。中间只用细分隔和小号 `≠`。

## 图 2｜场景对比
文字：`They put off the meeting until Friday. / 他们把会议推迟到了周五。`；`They called off the meeting. / 他们取消了会议。`

画面：上方日历显示会议从周一移动至周五；下方同一会议在日历中被取消，不出现新日期。

## 图 3｜一句话规则
文字：`put off = 改到以后 / call off = 直接取消 / 有新日期 / 没有了`

画面：左侧“周一 → 周五”的连续箭头，右侧单个日期被划掉，底部独立口诀卡片。

## 图 4｜自测
文字：`1. The game was ___ until next week. / 2. The game was ___ and won't be rescheduled. / put off 还是 called off？`

画面：第一题为比赛门票日期改到下周；第二题为暴风雨中的空球场和被划掉的比赛标记。不显示答案或勾叉。

## 图 5｜答案复习
文字：`1. The game was put off until next week. / 2. The game was called off and won't be rescheduled. / 有新日期 / 不再改期`

画面：第一题鼠尾草绿勾选并突出新日期，第二题杏陶色勾选并突出取消标记，底部独立口诀卡片。

生成前自检：竖版 3:4；不裁字；同一日历和机位；第 4 页不泄露答案；遮住文字后仍能看懂“改期 / 取消”；不生成日历小字、品牌或装饰乱码。
