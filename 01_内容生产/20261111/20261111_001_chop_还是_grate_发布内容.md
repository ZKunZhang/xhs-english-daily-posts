# 发布标题

都是弄碎：用刀切，还是擦板擦？

# 发布正文

胡萝卜变小了，可以是用刀切出来的，也可以是在擦板上擦出来的。“弄碎”没说清动作，英语会说得更具体。

Chop the carrot.
把胡萝卜切碎。chop 在这里强调切成小块。

Grate the carrot.
用擦板把胡萝卜擦碎。grate 强调食材在擦板上摩擦、变成细碎的小片或丝。

一句话记住：备菜时，chop 看切碎，grate 看用擦板擦碎。

同一种食材可以采用两种处理方式，选择哪种表达要看实际动作。grate 不一定都擦成长丝，结果也可能是细碎的小片；不要只看“是不是很碎”。

再看一组：
Chop the onion.
把洋葱切碎。
Grate the cheese.
用擦板把奶酪擦碎。

先别看答案：选更贴合所描述动作的词。

1. 用刀把洋葱切成小块。
___ the onion.（Chop / Grate）
2. 把奶酪在擦板上擦成细碎的小片。
___ the cheese.（Chop / Grate）

答案和理由在第5页。

用 Chop ... 或 Grate ... 写一句你准备食材时会说的话。
