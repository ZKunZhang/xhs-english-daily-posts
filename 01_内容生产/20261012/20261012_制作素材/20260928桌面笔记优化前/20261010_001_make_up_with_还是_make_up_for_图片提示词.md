# 来源与语言边界

三库及最新明细未命中同组。新稿；和好与补偿允许重叠，不通过礼物推断他人接受。

两件事可以同时发生。做饭或送礼可能是弥补的方式，但不自动证明对方已经接受、双方已经和好。make up for 也可以接名词，如 lost time。
