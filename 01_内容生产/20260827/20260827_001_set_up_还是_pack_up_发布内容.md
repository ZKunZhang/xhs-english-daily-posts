# 发布标题

set up 是开始搭，pack up 是结束收

# 封面文案

同一顶帐篷

开始前搭好

结束后收好

# 发布正文

露营开始和结束都在忙装备：一个让装备进入使用状态，一个把装备收好带走。

We set up the tent before dark.

我们在天黑前搭好了帐篷。

We packed up the tent the next morning.

第二天早上，我们把帐篷收好了。

一句话记住：

set up = 使用前搭好、布置好

pack up = 使用后收好、装走

先别看答案：

1. Let's ___ the camera.
2. It's time to ___ and go home.

评论区只写 1.___ 2.___，关键是活动准备开始还是已经结束。
