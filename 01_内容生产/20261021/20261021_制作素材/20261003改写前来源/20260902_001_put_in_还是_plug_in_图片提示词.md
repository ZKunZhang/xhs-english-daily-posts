# 视觉可行性

排期角色：主推“动词短语 + 具体生活场景”池。封面先呈现同一盏台灯，再呈现灯泡进入灯座 / 插头进入插座并通电两个动作和最终结果；遮住文字仍须能判断放入物体还是接通电源。

同一张书桌、同一盏台灯：put in 表现灯泡旋入灯座，plug in 表现电源插头插入墙上插座。接口形状和最终结果不同，遮住文字仍能判断。

- 版式家族：同一台灯 / 两步安装动作。

- 固定主体：同一双手、台灯、书桌、墙面插座和晨间光线；复古家电说明书式钢笔线描，局部平涂与旧纸网点；不是水彩，不是 PPT。

# 5 页视觉规划

## Page 01｜封面

严格 3:4 竖版并遵守安全区；统一现代黑体与无衬线体、最多两种字重；无品牌、乱码、霓虹渐变或贴纸堆叠。文字仅为 put in / 放进灯座 / plug in / 接上电源。上方灯泡进入灯座，下方插头进入插座。

## Page 02｜场景对比

继承双手、台灯与机位。文字：Put in the new light bulb carefully. / 小心地装入新灯泡。 / Plug in the lamp when you're finished. / 装好后把台灯插上电源。

## Page 03｜一句话规则

画面简化为容器轮廓与电源插座。文字：put in = 把物体放入位置 / plug in = 把设备接上电源。

## Page 04｜自测

建立电池仓和低电量笔记本两个情境。文字：1. ___ the batteries before you close the cover. / 2. The laptop is almost dead. I need to ___ it ___. / put in 还是 plug in？不出现答案或提示色。

## Page 05｜答案复习

完全复用第 4 页，只增加答案。文字：1. Put in / 2. plug in / 物体进入位置 / 设备接上电源。
