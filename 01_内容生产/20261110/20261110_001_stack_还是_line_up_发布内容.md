# 发布标题

盘子摞一叠，还是排一行？

# 发布正文

同样是把盘子摆好，一种往上摞，另一种在桌上排成一行。中文都能说“摆整齐”，英语要看你摆出的样子。

Stack the plates.
把盘子摞起来。stack 在这里强调上下叠成一堆。

Line up the plates.
把盘子排成一行。line up 在这里强调排列成行。

一句话记住：摆物品时，stack 看叠成堆，line up 看排成一行。

两词不必互相排斥：几叠已经摞好的盘子，也可以再排成一行。这里比较的是单个盘子怎样摆，不是“所有东西只能选一种”。

再看一组：
Stack the boxes.
把箱子叠起来。
Line up the shoes.
把鞋子排成一行。

先别看答案：选更贴合所描述摆法的表达。

1. 把几个箱子一个放在另一个上面，叠成一堆。
___ the boxes.（Stack / Line up）
2. 把几双鞋沿着墙边排成一行，没有上下叠放。
___ the shoes.（Stack / Line up）

答案和理由在第5页。

用 Stack ... 或 Line up ... 写一句你整理物品时会说的话。

每天一组生活里最容易混的英语。
