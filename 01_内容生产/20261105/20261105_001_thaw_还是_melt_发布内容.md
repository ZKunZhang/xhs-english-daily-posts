# 发布标题

鸡肉解冻后还是肉，黄油融化后呢？

# 发布正文

冻鸡肉恢复到不冻结的状态，和黄油融化成液体，中文都可能说“化了”，英语关注的变化却不同。

Thaw the chicken.
把鸡肉解冻。thaw 侧重从冻结状态恢复过来，鸡肉仍是鸡肉。

Melt the butter.
把黄油融化。melt 侧重融化，固体常变软或变成液体。

一句话记住：thaw 看解冻；melt 看融化。

冰雪上两词可能重叠，因为解冻和融化可以同时发生。别只凭“有没有滴水”或“有没有加热”判断；关键是你想强调的状态变化。

再看一组：
Thaw the bread.
把冷冻面包解冻，面包恢复到不冻结的状态。
Melt the chocolate.
把巧克力融化成液体。

先别看答案：选更贴合所描述变化的词。

1. 冷冻面包恢复不冻结，仍是面包。
___ the bread.（Thaw / Melt）
2. 巧克力从固体变成液体。
___ the chocolate.（Thaw / Melt）

答案和理由在第5页。

用 Thaw ... 或 Melt ... 写一句厨房里会用到的话。
