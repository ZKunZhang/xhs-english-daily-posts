# 发布标题

同一件外套，两种扣好方式

# 发布正文

同一件外套，里面有拉链，外层还有纽扣。“把外套扣好”可以是两种动作，看你手上动的是哪种扣件。

I zipped up my jacket.
我拉上了外套的拉链。zip up 说的是用拉链合上。

I buttoned up my jacket.
我扣上了外套的纽扣。button up 说的是用纽扣扣好。

一句话记住：拉上拉链用 zip up，扣上纽扣用 button up。

再看一组：
Zip up your bag.
把包的拉链拉上。
Button up your shirt.
把衬衫的纽扣扣好。
选择依据是实际扣件，不是“包一定用 zip、衣服一定用 button”。同一件有拉链和纽扣的外套，可以先 zip up，再 button up；具体顺序按你怎么穿。

先别看答案：选更贴合这次动作的说法。下面说的是同一件既有拉链、又有纽扣的外套。

1. 先把拉链拉到领口。
I ___ my jacket.（zipped up / buttoned up）
2. 再把外层纽扣逐颗扣好。
I ___ my jacket.（zipped up / buttoned up）

答案和理由在第5页。

你今天穿的衣服是哪种扣件？选 zip up 或 button up，写一句实际动作。
