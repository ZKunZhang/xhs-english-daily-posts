# 发布标题

处理同一根黄瓜：削皮还是切片？

# 发布正文

黄瓜还完整，只是外皮削掉了；另一根已经变成一片片。都是处理食材，英语要看你做了哪种动作。

Peel the cucumber.
给黄瓜削皮。peel 说的是去掉外皮。

Slice the cucumber.
把黄瓜切成片。slice 说的是切出薄片。

一句话记住：食材场景里，peel 看去皮，slice 看切片。

同一根黄瓜可以先削皮，再切片；也可以带皮切片。slice 不表示一定去过皮，peel 也不限定只能用刀。

再看一组：
Peel the apple.
给苹果削皮。
Slice the apple.
把苹果切成片。两句都自然，强调的动作不同。

先别看答案：选更贴合所描述动作的词。

1. 去掉土豆的外皮，土豆仍是完整的。
___ the potato.（Peel / Slice）
2. 把黄瓜切成一片片薄圆片，保留外皮。
___ the cucumber.（Peel / Slice）

答案和理由在第5页。

用 Peel ... 或 Slice ... 写一句你准备食材时会说的话。

每天一组生活里最容易混的英语。
