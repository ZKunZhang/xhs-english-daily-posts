# 素材改写

读取实际正文或截图，不凭标题、摘要补写观点。所需来源不可读时说明缺失，完成独立部分；纯来源提炼任务请求可读素材，不冒充已读。

1. 区分语言事实、作者观点和包装，保留来源链接。
2. 按[工作流](../../workflow.md)去重，报告命中位置；按[选题门槛](../../templates/xhs_post_template.md)判断能否构成自然 A/B。单点纠错标为补充内容，不硬凑对比。
3. 核验存疑用法，重写生活场景、例句和结构，不照搬独特表达或编造来源观点、数据。
4. 提炼任务交付结论、来源及改造方向；发布稿任务按[单篇技能](../xhs-english-daily-producer/SKILL.md)完成两份文本。来源说明留在发布正文之外。
