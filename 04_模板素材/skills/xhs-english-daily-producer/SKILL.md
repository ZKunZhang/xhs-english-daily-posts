# 单篇日更

新稿读取[定位](../../../05_账号定位/账号定位.md)、[工作流](../../workflow.md)和[单篇模板](../../templates/xhs_post_template.md)；标题与互动分别按需读[标题模板](../../templates/xhs_contrast_title_image_template.md)、[互动模板](../../templates/xhs_engagement_conversion_template.md)。局部修改只查受影响部分。

1. 去重、核对排期，按模板六项门槛筛题。未指定题目时继续寻找合格题；指定题不合格则说明缺口。
2. 用生活场景、短例句和一句判据讲清区别；重叠用法的练习问更自然或更常见的选择。
3. 完成标题、正文、自测和一个主评论动作。预告与回复承诺须有排期或授权依据，否则用共创邀请。
4. 按[视觉制作](../xhs-english-visual-director/SKILL.md)完成五页提示词；要求出图时继续生成与验收。
5. 按工作流保存两份文件，核对日期、配对、语义和答案。发布稿只留可发布内容；评分与来源摘要放交付说明，重制记录按工作流保存。
