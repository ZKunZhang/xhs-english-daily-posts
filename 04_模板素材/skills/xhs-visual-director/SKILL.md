# 英语辨析视觉策略

决定这篇的点击理由、内页回报和具体改动。先读目标稿并查看相关实图，区分线上版本、本地稿与提示词。首次设计读[定位](../../../05_账号定位/账号定位.md)；涉及表现时读[数据索引](../../../03_数据复盘/README.md)中的最新结论及[复盘口径](../../../03_数据复盘/规则/复盘规则.md)。边界案例按需查[账号案例](references/account-cases.md)。

## 证据决定改哪里

按同观察窗口和当前阶段目标比较；小样本、窗口不足须保留不确定性，历史数字不作固定阈值。

| 证据 | 优先动作 |
| --- | --- |
| 点击弱，收藏或带粉有价值 | 保留知识点，检查抽象标题、答案堆满、场景含糊，先改入口 |
| 点击尚可，收藏弱 | 查承诺兑现、使用边界、例句与迁移自测，别自动放大标题 |
| 点击、收藏都弱 | 查真实混淆与需求；只有可画性时建议降级或换题 |
| 浏览下降但点击改善，或涨粉降幅更大 | 查曝光来源、新旧笔记、主页访问及关注承接；缺数据保留归因缺口 |
| 用户觉得不吸引人，无线上数据 | 查层级、人物比例、重复构图和点击理由，实改一个关键变量；反馈不当效果证据 |

仅禁止私信不能推定限制推荐。换题、改期或发布只在授权范围内执行。

## 把内容变成画面

- 找中文使用者真正容易混淆的点；相反动作不自动等于有学习价值。一篇一个主钩子，正文有答案，重叠用法不画成绝对对错。
- 按[视觉系统](../../templates/xhs_visual_system.md)选动作对照、场景判断或文字主导，给一个有理由的推荐；额外标题需求用[标题技能](../xhs-english-title-editor/SKILL.md)。
- 提示词明确准确文案和阅读顺序、完整 A/B、场景与主体位置、画面占比、安全留白、沿用元素和本次改变。手机缩略图须能识别主题与学习理由。
- 按[页面职责](../../templates/xhs_contrast_title_image_template.md)兑现封面承诺：对比、边界、迁移题、完整答案各有收获。
- 再次被否定时解决上一版可见问题，改变对应层级、场景或构图，不只换问句；不把字越少越好当规则。

## 执行与复盘

决策与参考版本写入目标提示词制作记录，再交[视觉制作](../xhs-english-visual-director/SKILL.md)完成已授权交付，不循环诊断。仅提示词不出图；先看一张则独立预览，明确采用后备份替换。

逐张验收；用户接受的偏差记录适用范围。用户选中不代表线上有效，09-08 封面仍是试用版本。发布后记录实际标题／封面、修改时间和内容变化，按准确 24h／72h 口径比较，提炼值得再测的表达方式，不把单篇结果固化为长期模板。

方法借鉴与许可保留在[来源档案](../../参考资料/xhs-visual-director-skill_20260907/来源.md)；日常不加载外部风格库。
