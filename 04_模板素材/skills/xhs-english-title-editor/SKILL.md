# 小红书英语标题编辑

把英语差异转成能在生活中看见的后果，再产出一个最终发布标题和三行以内封面文案。

## 必读

完整读取：

- `../../templates/xhs_contrast_title_image_template.md`
- `../../../05_账号定位/账号定位.md`
- 目标 `*_发布内容.md` 或用户确认的规则与例句

## 决策顺序

1. 写清形式差异、语义变化和具体生活后果。
2. 后果型标题优先；动作对比型其次；“原来不一样”只作保底。
3. 检查标题能否由正文完全兑现，是否把倾向夸大成绝对规则。
4. 封面只保留完整 A/B 和两个短动作，总体不超过三个信息组。

## 禁止

- 不用“救命”“保姆级”“全网最全”、emoji 堆叠、考试包装或虚构的“很多人都错”。
- 不为追求点击把一个正确项和一个错句包装成 A/B 对比。
- 不输出十几条通用爆款标题矩阵。默认内部比较三种路由，只交付最终选择；用户明确要备选时再附两条。
- 不把封面改成通用广告、撕纸拼贴、满版大字或电影海报。

## 输出

```markdown
# 发布标题

{{最终标题}}

# 封面文案

{{完整 A/B 或小差异}}

{{动作/后果 A}}

{{动作/后果 B}}
```
