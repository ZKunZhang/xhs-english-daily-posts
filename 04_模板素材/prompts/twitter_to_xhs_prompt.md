# Twitter/X 英语内容转小红书｜任务入口

按 [外部英语素材原创改写技能](../skills/xhs-english-source-adapter/SKILL.md) 执行。原文只作为知识事实线索；不直译，不复制原文钩子、句式或叙述顺序。

## 输入

```text
原文 / 截图 OCR / 可访问链接：
希望保留的核心知识点（可空）：
目标日期（可空）：
已知重复或原稿路径（可空）：
是否为用户明确要求的数据重制：是 / 否
额外限制（语气、场景、禁用内容等）：
```

重复知识点默认停止；明确重制时记录原稿与实质改动。达标内容交付 `发布内容.md` 和 `图片提示词.md`，其余情况只报告审核结论与缺口。
