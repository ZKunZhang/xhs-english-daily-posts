# 小红书英语互动转粉模板

适用定位：生活场景里的高频英语易混表达。

## 使用原则

- 每篇只解决一组表达，不为了评论扩成泛话题。
- 第 5 页完整给答案，评论动机来自个人表达、批改收益或参与下一篇。
- 每篇只选一种主互动，不同时要求投票、造句、解释和征题。
- 封面保留完整 A/B，但不在标题、封面、首段连续三次讲完同一映射。

## 发布标题

优先使用具体场景问题：

```text
[生活场景]，到底用 A 还是 B？
```

避免：

```text
A 是……，B 是……
都是……，一个……，一个……
```

除非这个结果对比本身足够反常。

## 五页职责

### 第 1 页：场景冲突

- 一个具体人物、地点和动作。
- 完整出现 A / B。
- 留下一个需要判断的问题，不堆规则。

### 第 2 页：两个动作或结果

- 同一人物、物品、机位或时间线。
- 只改变一个关键变量。

### 第 3 页：一句话边界

```text
A = [判断点]
B = [判断点]
```

必要时说明真实灰区，不制造绝对规则。

### 第 4 页：应用任务

从以下选一种：

1. 个人选择。
2. 用户造句。
3. 场景判断 + 理由。
4. 提交中文场景。
5. 跨帖复习。

### 第 5 页：答案与追更

- 完整答案。
- 一个最容易错的判断点。
- 系列编号。
- 下一篇具体预告或评论征集。

## 正文结构

```markdown
# 发布正文

[两行以内的生活冲突，不先重复完整答案。]

[A 例句]
[中文与判断点]

[B 例句]
[中文与判断点]

一句话记住：……

[保留两道练习，答案在第 5 页。]

[只放一个主评论任务。]

每天一组生活里最容易混的英语。
下一篇：[具体场景或表达]。
```

## 五种互动文案

### 个人选择型

```text
今晚你会 A 还是 B？留 A/B，再加一个原因。
```

### 我来批改型

```text
用 A 写一句和你有关的话，我会看前 10 条并给出更自然的改法。
```

### 场景征集型

```text
留一句你拿不准的中文场景，我从评论里选 3 句做周四的英语门诊。
```

### 答案加理由型

```text
先选 A/B，再写一个判断理由；我会置顶最容易错的判断点。
```

### 下期投票型

```text
下一篇先讲 A/B 还是 C/D？只投一组，票高的先发。
```

## 自发评论

自发评论只做三件事之一：

- 承诺本条回复范围与时间。
- 征集下一期场景。
- 发起明确投票。

不得再机械增加一道已经能在末页找到答案的填空题。

## 数据记录

```text
发布日期
实际标题
互动类型
24h / 72h 曝光、观看、点击率、收藏、涨粉
用户原始评论数（扣除账号）
独立评论人数
账号回复数
二次对话人数
有效评论率 = 用户原始评论数 / 观看
每千曝光涨粉 = 涨粉 / 曝光 * 1000
```
