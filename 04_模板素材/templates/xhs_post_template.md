# 小红书英语单篇发布稿模板

适用于“生活场景英语易混点整理号”的日更单篇。每篇交付两份文本：`发布内容.md` 与 `图片提示词.md`。阶段目标、内容比例与数据判断以 [数据复盘索引](../../03_数据复盘/README.md) 指向的最新正式结论为准，不在模板里固化旧数字。

## 产出前记录

```text
知识点：
去重命中：未命中 / 命中（附文件）
处理：新稿 / 用户明确重制
若为重制，原稿：
本次实质改动：场景 / 规则边界 / 例句 / 自测 / 互动 / 视觉
```

按[工作流](../workflow.md)处理重复、现稿复用和已批准重制；重制审核记录原稿与实质改动。

## 六项选题门槛

每项 1 分：

| 检查项 | 达标标准 |
| --- | --- |
| 高频 | 18—34 岁用户在口语、写作或生活中真会用 |
| 真对比 | A/B 两边都是成立的表达，不是正确项对错句 |
| 共同认知 | 中文意思接近，用户有合理的混淆动机 |
| 具体后果 | 可以用位置、动作、对象或时间变化呈现差异 |
| 一句话规则 | 不用语法术语也能讲清 |
| 可视化 | 能为两边各写一句短例句，画面明显不同 |

- `5—6 分`：进入日更主线。
- `4 分`：作为备选，先补强具体后果。
- `0—3 分`：暂停，不生成完整稿。
- 单点纠错、活动前缀和纯低频拼写差异不进入主线。
- A/B 有重叠时写成“常见用法倾向”，说明重叠范围；无法简洁说明时降为备选。

标题选择与五页职责见 [强对比标题与图文模板](xhs_contrast_title_image_template.md)，互动与追更见 [互动转粉模板](xhs_engagement_conversion_template.md)，画面、排版与逐页提示词只按 [视觉系统](xhs_visual_system.md) 执行。

## 发布前检查

- 两份文本内容一致，固定 5 页、3:4；第 4 页没有答案，第 5 页有两题完整答案与理由。
- 互动任务独立于两道自测，没有用投票或评论题替代第 4 页。
- 自测语境足以支持目标答案；有重叠时改问“哪种更常见/更自然”，并说明另一种也成立。
- 英语拼写、介词、冠词、时态和标点自然；标题、口诀没有把用法倾向写成绝对规则。
- 没有虚构下一篇选题、回复数量或发布时间承诺。
