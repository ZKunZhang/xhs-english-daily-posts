# 五页视觉与生图流程

## 母版前缀

每页提示词都完整包含以下等价信息，不能用“同上”代替：

> 1080×1440，严格 3:4；暖奶油白背景，深咖灰文字，A 鼠尾草绿，B 杏陶色；低饱和手绘编辑插画、细线描、轻纸张颗粒；固定人物、服装、道具、环境、机位和光线；无品牌、乱码、霓虹、3D、撕纸、贴纸、广告海报感或随机版式漂移。

## 五页职责

- Page 1 封面：同一主体的两个互斥动作；只放 A/B 和两个短结果。
- Page 2 场景：A/B 各一个真实例句，并让画面演出例句动作。
- Page 3 规则：保留同一环境，用最简单的位置、方向或状态变化呈现唯一判断变量。
- Page 4 自测：两个新但同类的场景，不出现答案色、勾叉或答案词。
- Page 5 答案：完全复用 Page 4 的人物、机位与裁切，只增加答案色、答案和一句理由。

## 封面确认门槛

重制或首次使用时先只生成封面。缩小查看并遮住文字，逐项检查：

- 两个动作是否立即不同？
- 人物、道具、视角是否足够相同，便于比较？
- 是否有具体结果，而不是空白屏幕或抽象卡片？
- 标题是否在一秒内读清？

任一项失败，先修构图，不靠增加箭头、颜色或解释文字补救。

## 图像提示词结构

按顺序写：用途 → 参考图角色 → 场景 → 同一主体 → A/B 唯一变量 → 风格 → 构图 → 逐字文字 → 必须保持 → 禁止项。

需要在图中直接生成文字时，只保留少量短文案并要求逐字呈现。长例句优先后期排版；如果环境没有排版工具，生成后必须逐字验收。

## 最终验收

- 五张均为 1080×1440。
- 封面视觉最强，图 2 具体，图 3 最简，图 4 留白，图 5 答案明确。
- A/B 色义全篇一致。
- 第 4、5 页除答案状态外完全一致。
- 每张图中的英文、中文、标点和数字均人工查看通过。
