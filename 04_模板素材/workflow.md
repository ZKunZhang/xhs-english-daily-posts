# 内容生产工作流

本文件维护跨技能的文件与状态约定。执行用户请求对应的部分，不要求每次从选题走到发布。

## 规则来源

| 决策 | 维护位置 |
| --- | --- |
| 定位与受众 | [账号定位](../05_账号定位/账号定位.md) |
| 当前数据与阶段策略 | [数据索引](../03_数据复盘/README.md)指向的最新正式结论 |
| 正式发布顺序 | 数据索引中的当前执行手册及已确认日期目录，优先其最新明确修订 |
| 六项门槛与发布稿结构 | [单篇模板](templates/xhs_post_template.md) |
| 标题、封面文字与五页职责 | [标题图文模板](templates/xhs_contrast_title_image_template.md) |
| 评论与追更 | [互动模板](templates/xhs_engagement_conversion_template.md) |
| 画面、提示词与实图验收 | [视觉系统](templates/xhs_visual_system.md) |

同一规则只在所属文件维护；README 是导航，Skill 是任务入口，prompts 是输入示例。模板默认值可按用户明确要求调整；不要把历史实验比例、例子或内部检查变成新的硬门槛。

## 选题与去重

新建选题时，按 A/B 表达及同义知识点搜索待发布、已发布及 `06_内容管理` 中的候选库存和历史库存，再查数据索引标记的最新笔记明细。库存命中不代表已经发布。先定位文件和相关行，不全文加载历史稿。最新明细若为 Excel，读取对应工作表；不可用时说明去重覆盖缺口，不宣称全库无重复。

已发或已排选题默认复用现稿或换题；用户指定重制或正式排期批准数据重制时，保留原稿，记录来源和实质改动，不靠换标题伪装新选题。单篇重制记录写入图片提示词文件的“制作记录”（内部信息，不上图）；只做审核时写在审核结果中。只改现稿标题、标点或图片时，不重跑全库选题审核。

## 日期与文件

`01_内容生产` 根层仅放待发布稿的日期目录。发布手册放 `06_内容管理/发布排期/`，跨篇预览放 `06_内容管理/配图预览/`；两者通过[内容管理入口](../06_内容管理/README.md)导航，不散落到待发布目录。

1. 优先用户指定日期，其次已确认排期。同题已有稿时修改原稿；新题没有日期时使用不早于今天且晚于正式排期最后一天的下一个空闲日，注明这是草稿安排，不擅自改正式排期。
2. 待发布稿进入 `01_内容生产/YYYYMMDD/`。每篇默认保存两份文本：

   ```text
   YYYYMMDD_序号_知识点_发布内容.md
   YYYYMMDD_序号_知识点_图片提示词.md
   ```

3. 标题写在发布内容顶部；五页文案和逐页提示词维护在图片提示词文件。英语表达不加 Markdown 反引号。不另造完整发布稿或封面标题方案。
4. 请求出图时，把最终成图保存到同一日期目录，名称为同一前缀加 `_封面.png`、`_图2_场景对比.png`、`_图3_一句话规则.png`、`_图4_自测.png`、`_图5_答案复习.png`。尺寸验收目标为 1080 × 1440。
5. 日期目录根层仅放该篇五张最终成图；母图、底图、版本和预览放入 `YYYYMMDD_制作素材/`。生成或重制时保留已有素材，避免覆盖未经指定的文件。

当前工具能力不足时交付已完成部分并明确缺项，不把提示词当作已完成出图。只要求标题、审核或规划时，交付该结果，不附加整套文件或生成图片。

## 排期、发布与归档

只要求规划时交付排期方案，标明相对现有排期的变化；明确要求重排或执行方案时直接落实授权范围。执行手册、日期目录和排期表不一致时，按最新明确修订核对；仍无法确定实际安排才询问，期间继续审核候选。

正式改期时检查目标冲突，同步目录名、文件名前缀、排期和相邻篇预告；优先移动复用现稿，不为改日期复制图片。未定日期、待筛选的候选进入 `06_内容管理/候选库存/`；撤出稿、重构稿和改写前版本进入 `06_内容管理/历史库存/` 下对应月度重构池，不占日更日期。库存目录中的日期保留为来源，不自动成为发布计划。

获得发布证据或用户确认后，将已发布作品归档到 `02_已发布/`，同步发布手册、配图预览和索引中的文件链接。日期目录全部发布才整体移动；同日仍有待发布作品时只移动已发布那篇的文本、图片及素材。旧归档保持原结构，除非任务就是迁移历史。

新数据按导出日期进入 `03_数据复盘/原始数据/`，保留原文件；更新数据索引，按[复盘规则](../03_数据复盘/规则/复盘规则.md)记录结论。草稿日期、文件位置和内部自测均不能代替真实发布或平台数据。

## 完成标准

检查本次改变的内容及直接依赖：正文与五页语义一致、文件配对、日期与链接有效；有成图时逐张看文字、动作、版式和尺寸。发现问题再扩大检查，通过后交付，不重复跑无关流程。最终回复给出产物链接、验证结果和实际缺项。
