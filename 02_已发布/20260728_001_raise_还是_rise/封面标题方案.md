# 封面标题方案｜raise / rise

## 路由结果

- 内容赛道：2 自我成长（英语学习）
- 匹配钩子：C 反常识对比、D 如何方法
- 核心观点：`raise` 和 `rise` 都可以表示“升起”，但一个是把某物举起，一个是某物自己升起。

## 方案一｜C 反常识对比 × 对比撕裂型

### 1-1

- 标题：`多一个 a，自己升起就变成把它举起`
- 封面：`raise ≠ rise / 把它举起 / 它自己升起`
- 追溯：C + 2 自我成长，参考案例库 #010

### 1-2

- 标题：`都是“升”，一个举别人，一个自己升`
- 封面：`同样是升 / raise 举起它 / rise 自己升`
- 追溯：C + 2 自我成长，参考案例库 #007

### 1-3

- 标题：`raise 和 rise，动作的主人完全不同`
- 封面：`别把升起混了 / raise 动手举 / rise 自己升`
- 追溯：C + 2 自我成长，参考案例库 #010

## 方案二｜D 如何方法 × 结论前置型

### 2-1

- 标题：`怎么分清 raise 和 rise？看谁在用力`
- 封面：`看谁用力 / raise 把它举起 / rise 自己升起`
- 追溯：D + 2 自我成长，参考案例库 #017

### 2-2

- 标题：`用一个动作分清 raise 和 rise`
- 封面：`一个动作分清 / 举起它 raise / 自己升 rise`
- 追溯：D + 2 自我成长，参考案例库 #019

### 2-3

- 标题：`raise 和 rise，到底哪个后面要加东西？`
- 封面：`后面加什么 / raise 要说举起谁 / rise 不用加`
- 追溯：D + 2 自我成长，参考案例库 #017

## Top 3 推荐

1. 方案 1-1：把一个字母的差别直接翻译成动作后果，最符合账号已验证的“微小差异 + 具体后果”模型。
2. 方案 1-2：中文冲突清晰，不懂语法术语也能立即看懂。
3. 方案 2-1：用“谁在用力”作为判断动作，口语化且容易记。

最终采用方案 1-1。
