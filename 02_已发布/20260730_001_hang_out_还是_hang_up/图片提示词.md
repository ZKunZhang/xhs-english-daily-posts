# 图片提示词｜hang out / hang up

主题：hang out 还是 hang up

统一风格：小红书英语学习笔记，竖版 3:4，温暖米白纸张质感，黑色清晰大字，浅蓝标记 `hang out`，浅橙标记 `hang up`，少量朋友聚会、咖啡杯、手机和通话结束图标。每页只有一个视觉中心，留白充足，不要 PPT、商务汇报、复杂人物、贴纸堆叠或密集表格。所有英文逐字准确，移动端缩略图清晰可读。

## 图 1｜封面

文字：`hang out ≠ hang up / 和朋友出去玩 / 把电话挂掉`

画面：左右双场景。左侧两三位朋友在咖啡店轻松聊天；右侧手指点击手机的红色结束通话按钮。用人物相聚和电话断开强化两种完全不同的场景。

## 图 2｜场景对比

文字：`I hung out with my friends yesterday. / 我昨天和朋友们出去玩了。`；`Don't hang up yet. / 先别挂电话。`

画面：上下两张生活场景卡。上方是朋友聚会，下方是正在通话的手机；分别突出相处和结束通话。

## 图 3｜一句话规则

文字：`hang out = 和朋友待在一起、出去玩 / hang up = 挂断电话 / 人出去聚：hang out / 电话挂掉：hang up`

画面：左侧人物围坐聊天指向 `hang out`，右侧手机红色挂断键指向 `hang up`。规则只保留这四行。

## 图 4｜自测
