知识点：keep up with 和 catch up with 的区别

## 图 2｜场景对比页

顶部写：
场景对比

左侧便签：

右侧便签：
I need to catch up with the class.

## 图 3｜规则页

标题：
一句话记住

核心内容：
keep up with
= 跟得上 / 不掉队

catch up with
= 追上 / 赶上

底部小字：
keep 看持续跟住

catch 看从后面追上

## 图 5｜答案页

标题：
自测答案

答案内容：
1. I can't keep up with him.

他一直在说，你跟不住，所以用 keep up with。

2. I need to catch up with the class.

你已经落后，要追上去，所以用 catch up with。

底部口诀：
不掉队：keep up with

追上来：catch up with
