# 图片提示词

排期角色：主推“动词短语 + 具体生活场景”池。整组采用“封面提问 → 场景例句 → 一句话规则 → 留空自测 → 答案复习”的教学链路。封面不泄露答案；后续每张图都必须有可独立阅读的文字信息。

统一视觉：1080×1440、3:4；暖奶油白纸底、鼠尾草绿、杏陶色、炭黑；柔和水彩编辑插画与轻纸纹。同一公寓门口、年轻搬家者、纸箱、搬家车和日光。move in 始终表现为纸箱从门外进入空房，move out 始终表现为纸箱从房内走向搬家车。

封面文字：`中文都叫搬家 / 纸箱进门 / 还是出门？`

图2文字：`看纸箱往哪走 / move in / We’re moving in this Saturday. / 我们这周六搬进新家。 / move out / The old tenants moved out yesterday. / 原来的租客昨天搬走了。`

图3文字：`一句话记住 / move in = 搬进新住处 / move out = 从原住处搬走 / 看纸箱：进门 in，出门 out`

图4文字：`先别看答案 / 1. When can we ___? / 2. You must ___ by Friday. / 只看方向，先自己选`

图5文字：`答案来了 / 1. When can we move in? / 搬进新家 → move in / 2. You must move out by Friday. / 搬离旧家 → move out / 进门 in，出门 out`

实图验收：五张均包含所需文字；图4不泄露答案；进门与出门方向、人物动作和纸箱最终位置一致。
