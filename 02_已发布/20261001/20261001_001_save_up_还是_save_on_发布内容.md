# 发布标题

攒钱买相机，和骑车省车费，是两种“省”

# 发布正文

想买相机，每月留下一笔钱；改骑车上班，让交通费少一点。中文都能说“省钱”，英语说的重点不同。

I'm saving up for a camera.
我在攒钱买相机。save up 看的是把钱一点点留起来，为以后使用做准备。

I cycle to work to save on transport costs.
我骑车上班来省交通费。save on 看的是某项支出减少了。

一句话判断：save up 看“攒起来”，save on 看“在哪项开支上少花”。省下车费再存起来，这两件事完全可以同时发生。

再看一组：
We're saving up for a weekend trip.
我们在为一次周末旅行攒钱。

We share a room to save on accommodation.
我们合住一个房间，节省住宿费。旅行是攒钱目标，住宿是想减少的开支。

先别看答案。用完整英语表达下面两个重点：

1. 每月留下一点收入，准备以后买相机。补全：I'm ___ for a camera.
2. 已决定骑车通勤，想直接说“这样可以少花交通费”。补全：I cycle to work to ___ transport costs.

答案和理由在第5页。第二句里的省钱办法，也可以帮助第一句的攒钱计划。

你现在想为哪件事攒钱？用 I'm saving up for... 写一句自己的计划。
