# 图片提示词｜road / street

主题：`road` 还是 `street`

## 本次生成范围

- 图 1 使用上下双知识卡结构，作为全套视觉基准。
- 图 2—5 延续封面的暖白纸底、鼠尾草绿 `road`、杏陶色 `street`、圆角卡片和水彩编辑插画风。
- 各页场景不得只是重复封面：封面负责建立词义，图 2 负责生活例句，图 3 负责可视化规则，图 4—5 负责测试与答案。

## 执行方式（必须）

封面采用上下双知识卡结构，优先直接生成完整成品；若模型中文字不稳定，则改用两步制图：第一步生成无文字插画，第二步用固定模板叠加准确文字。最终画布统一为 1080 × 1440、竖版 3:4；模型若输出 2:3，使用同色背景向左右扩展为 3:4，不裁切卡片、文字或插画。安全区为左右各约 6%、顶部约 4%、底部约 4%。英文使用干净的无衬线体，中文使用现代黑体，全套最多两种字重，全部左对齐。

对立必须来自同一观察逻辑：`road` 画面强调道路连接两个地点并延伸到远方；`street` 画面强调道路两侧连续建筑、人行道和店面。不要靠粗撕裂、巨大 `≠`、高饱和红蓝或无关装饰补冲突。遮住文字后仍应看懂两者差异。

统一风格：小红书英语学习知识卡，竖版 3:4，延续 `floor / ground` 成图的温和生活插画风。背景为暖奶油白 `#F7F1E7`，`road` 使用低饱和鼠尾草绿和灰青色 `#829C8C`，`street` 使用柔和杏陶色 `#D49A78`，正文、中文和描边使用深咖灰 `#3F3A36`。插画采用柔和平涂、水彩晕染和少量纸张颗粒，光线明亮自然。不要撕纸、`≠`、高饱和红蓝或无关装饰。英文和中文必须逐字准确；除指定文字外，不生成招牌、路牌、店名或乱码。移动端缩略图中，单词和例句必须清晰可读。

统一构图约束：5 页保持同一套字体、纸张纹理、圆角插画框和配色。文字与插画明确分区，不把文字压在画面上。`road` 始终用鼠尾草绿，`street` 始终用杏陶色。英文是主要信息，中文只做一行辅助理解，字号和字重均低于英文；例句保持醒目。城市画面只保留楼房、店面、路灯和人行道；乡间画面保留道路、田野与远处村庄。

## 图 1｜封面

状态：已按“单词 + 英文释义 + 例句 + 场景配图”的知识卡结构重做。

文字：`Road / A route that connects one place to another. / 连接不同地点的道路 / This road leads to the village. / Street / A road in a town or city, usually with buildings on both sides. / 城镇里两边有建筑的街道 / There are many shops on this street.`

### 第一步｜生成插画素材（文字不稳定时使用）

分别生成两张可独立裁切的横向场景插画。

- `road` 场景：一条有明确中心线的乡间公路从近景出发，穿过开阔田野，最终连接到画面中央远处的小村庄。道路和目的地必须形成清楚的视觉连线，重点是“通向另一个地点”，不是普通田园风景。
- `street` 场景：一条城市街道位于两排连续的低层商店和公寓之间，两侧有人行道、少量路灯和无文字遮篷。建筑必须明显夹住街道，重点是“位于建筑之间”，不是单纯城市建筑风景。
- 两张插画采用相近的视角、地平线高度和主体比例，便于上下排列；主体集中、边缘保留裁切余量。
- 使用温和的编辑插画风、柔和平涂、轻微水彩边缘和克制的纸张颗粒。`road` 使用鼠尾草绿与灰青色 `#829C8C`，`street` 使用杏陶色 `#D49A78`。
- 插画内部不得出现任何字母、汉字、数字、路牌、店名、品牌、水印、卡片边框、标题区、撕纸边或排版留白框。

### 第二步｜固定模板排版

画布为 1080 × 1440，背景使用暖奶油白 `#F7F1E7`。上下放置两张近似等高的圆角知识卡，卡片使用白色或极浅暖白底、1 px 低对比描边，不使用厚框和明显阴影。

- 上卡为 `Road`，下卡为 `Street`；两卡之间保留稳定间距，不增加总标题、`≠` 或中文钩子。
- 每张卡按固定顺序左对齐：大号单词 → 英文释义 → 一行中文解释 → 加粗英文例句 → 横向场景插画。
- `Road` 和例句中的 `road` 使用鼠尾草绿；`Street` 和例句中的 `street` 使用杏陶色，其余英文使用深咖灰。
- 单词是第一视觉层级，例句是第二层级，插画是第三层级；英文释义清晰但较小，中文解释再小一级并使用常规字重。
- 两张插画等宽、圆角一致。允许适度压缩插画高度，但不能压缩文字行距或让长释义贴边。
- 不把任何文字压在插画上，不增加标题、页码、标签、图标、总结卡或装饰文案。

### 封面内容自检

- 遮住所有文字后，仍能看出上图道路连接远方村庄、下图街道位于连续建筑之间。
- 八段指定文字逐字准确，标点完整，顺序无误。
- 中文只解释词义，不重复翻译例句，不抢英文视觉层级。
- 封面不出现 `≠`、总标题、页码、标签、店名或装饰性文案。
- 不使用纯黑撕裂线、警示色、高饱和红蓝、贴纸堆叠或宣传海报式强对比。
- 成品必须为 3:4；移动端缩略图中，`Road`、`Street` 和两条例句完整清晰。

## 图 2｜场景对比

文字：`This road leads to the village. / 这条路通往村庄。`；`The café is across the street. / 咖啡馆就在街对面。`

画面：使用上下两张横向生活场景卡。上卡以行驶视角表现乡间公路从近景明确连接到远处村庄，村庄必须是清楚的目的地，不复用封面的正中央对称构图。下卡采用站在人行道一侧向街对面看的视角，对面咖啡馆用咖啡杯图标识别，街道必须横在人物与咖啡馆之间，让 `across the street` 一眼可见。允许一个小比例背影人物帮助建立“街对面”的视线关系。除咖啡杯图标外不出现招牌文字。

## 图 3｜一句话规则

文字：`road = 道路、路线 / street = 城镇建筑之间的街道 / 通远方 road，楼中间 street`

画面：左右两张竖向规则卡。`road` 卡用两个清晰地点标记加一条连续路线箭头，箭头必须沿道路从近景指向远处村庄，直观表达“连接两个地点”；`street` 卡用左右两侧向内的细括号标出连续建筑，中间保留完整街道，直观表达“建筑之间”。视觉标记保持低饱和，不做地图 App、路牌或复杂图标。下方单独放口诀卡，规则只保留指定三行，不添加解释。

## 图 4｜自测

文字：`1. This ___ leads to the airport. / 2. There are many restaurants on this ___. / road 还是 street？`

画面：上下两个等高圆角题目卡，文字在左、插画在右。第一题必须同时看见道路近景和远处机场航站楼，让道路承担“通往机场”的路线功能；第二题必须看见街道两边连续分布的餐馆、遮篷和少量室外桌椅，不能只在单侧堆放店面。餐馆只用餐盘或餐具图形识别，不出现文字招牌。测试页不显示答案、颜色暗示、勾叉，也不把 `road` 或 `street` 写进插画。

## 图 5｜答案复习

文字：`1. This road leads to the airport. / 2. There are many restaurants on this street. / 通远方 road，楼中间 street`

画面：严格复用图 4 的两个场景、裁切和布局，只揭示答案，不重新生成不同机场或不同街道。第一题高亮 `road` 并增加鼠尾草绿色勾选，第二题高亮 `street` 并增加杏陶色勾选。底部用独立暖白圆角卡片显示口诀。这样用户能把注意力放在答案变化上，而不是寻找两页画面的差别。
