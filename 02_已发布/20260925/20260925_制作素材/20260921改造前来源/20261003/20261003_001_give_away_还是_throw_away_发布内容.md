# 发布标题

旧外套交给别人还是丢进垃圾桶：give away / throw away

# 封面文案

give away / throw away

送给别人

当垃圾丢掉

# 发布正文

同一件不再穿的外套，give away 是让它去到别人手里，throw away 是把它当垃圾丢掉。

I’m going to give away this coat.

我准备把这件外套送人。

判断点：物品仍可使用，只是转给别人。

Don’t throw away the receipt.

别把收据扔掉。

判断点：物品被当作不要的东西丢弃。

一句话记住：处理物品时，give away 常表示免费送出或捐出，throw away 表示丢弃；give away 也可表示泄露秘密或暴露答案，要看宾语。

再看一组：

We gave away the extra chairs.

Throw away any spoiled food.

先别看答案：

1. These books are still useful. Let’s ___ them to the library.
2. This milk has spoiled. Please ___ it.

答案放在最后一页。
