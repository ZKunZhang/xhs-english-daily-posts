# 图片提示词

排期角色：主推“动词短语 + 具体生活场景”池。封面先呈现同一教室与同一叠纸，再呈现多人交向一人 / 一人分给多人两个方向和纸张最终去向；遮住文字仍须能判断集中还是分发。

1080×1440、3:4；固定奶油白、鼠尾草绿与杏陶色水彩母版。同一教室、老师、学生和练习纸；A 多名学生把作业集中交给老师，B 老师把练习纸分给多名学生。文字仅为 `hand in / 学生交上去 / hand out / 老师发下去`。

实图验收：文字正确；多人到一人、一人到多人的方向通过。

## 2026-08-26 优化版

- 统一奶油白、鼠尾草绿、杏陶色复古水彩风，固定左绿右橙。
- `hand in`：多名学生各拿一张纸，箭头和纸张汇聚到老师。
- `hand out`：老师手持一叠纸向多名学生分发，学生只伸空手接纸。
- 轮播顺序：封面对比 → 场景对比 → 一句话规则 → 自测 → 答案复习。
- 验收重点：英文与中文逐字正确；缩略图下仍可辨认 many → one / one → many；不出现反向递纸。
