# 母版锁定

Use case: scientific-educational. 制作一张小红书英语教学笔记图，竖版3:4，目标1080×1440。奶油色浅横线纸，自然窗光，近俯拍，木桌只露少量边缘。自然清楚的蓝黑圆珠笔手写中英文，少量浅绿/浅黄划线，简洁有语义的线稿。不用印刷体海报、贴纸、文具堆叠、品牌或密集排线。文字左右8%、顶部7%、底部10%安全区。全部文字逐字准确，允许换行不允许改词；英文清晰大字，中文清晰不连笔，手机阅读优先。 本篇主体与场景：厨房物件与手部近景，同一个带把白杯。上图手把杯子放回木桌上原先的淡圆形位置，下图手把同一个杯子收进橱柜。保持机位、杯子与手部线条一致，用清楚的桌面和橱柜位置而非单纯颜色区别。
