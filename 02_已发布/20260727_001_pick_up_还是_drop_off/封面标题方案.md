# 封面标题方案｜pick up / drop off

## 路由结果

- 内容赛道：2 自我成长（英语学习）
- 匹配钩子：C 反常识对比、D 如何方法
- 核心观点：`pick up` 和 `drop off` 都用于开车接送，但动作方向相反。

## 方案一｜C 反常识对比 × 对比撕裂型

### 1-1

- 标题：`up 换成 off，开车接人就变成送人了`
- 封面：`pick up ≠ drop off / 一个开车去接 / 一个送到后离开`
- 追溯：C + 2 自我成长，参考案例库 #007

### 1-2

- 标题：`同样是开车，一个去接，一个送到后离开`
- 封面：`同样开车 / 一个接人上车 / 一个送人下车`
- 追溯：C + 2 自我成长，参考案例库 #010

### 1-3

- 标题：`pick up 和 drop off，行车方向完全相反`
- 封面：`别把接送混了 / pick up 去接 / drop off 送到`
- 追溯：C + 2 自我成长，参考案例库 #007

## 方案二｜D 如何方法 × 结论前置型

### 2-1

- 标题：`怎么分清 pick up 和 drop off？看上下车`
- 封面：`看上下车 / 接人用 pick up / 送人用 drop off`
- 追溯：D + 2 自我成长，参考案例库 #017

### 2-2

- 标题：`用一个动作分清 pick up 和 drop off`
- 封面：`一个动作分清 / 接人上车 / 送人下车`
- 追溯：D + 2 自我成长，参考案例库 #019

### 2-3

- 标题：`pick up 和 drop off，到底哪个是接人？`
- 封面：`接人还是送人 / 看清 up 和 off / 别坐反方向`
- 追溯：D + 2 自我成长，参考案例库 #017

## Top 3 推荐

1. 方案 1-1：把一个小词的变化直接翻译成行程结果，最符合账号已验证的标题模型。
2. 方案 1-2：生活场景清晰，用户不懂语法也能立即理解冲突。
3. 方案 2-1：搜索意图明确，适合作为较稳妥的知识型标题。

最终采用方案 1-1。
