# 封面标题方案｜show up / show off

## 路由结果

- 内容赛道：2 自我成长（英语学习）

- 核心观点：`show up` 和 `show off` 只换一个词，却分别表示到场和炫耀。

## Top 3 推荐

1. 方案 1-1：把 `up / off` 的微小变化直接连接到“出现 / 炫耀”两个冲突后果，最贴合账号模型。
2. 方案 1-2：“终于到场 / 生怕别人看不见”自带人物情绪，画面和讨论感更强。
3. 方案 2-1：给出“看人来没来”的即时判断方法，适合拉收藏。
