# 发布标题

客人快到了：clean up 还是 tidy up？

# 发布正文

客人快到了，台面上的咖啡要擦掉，散乱的文件要归整。中文都可以说“收拾一下”，英语常见侧重点不同。

He cleaned up the coffee that had spilled on the table.

他清理了洒在桌上的咖啡。重点是去掉污渍和脏乱，所以这里用 clean up。

He tidied up the papers on the table.

他把桌上的文件整理整齐了。重点是调整位置、恢复整齐，所以这里用 tidy up。

一句话记住：clean up 常强调让人或地方变干净，也可以包含收拾残局；tidy up 常强调把散乱的物品归位、变整齐。两者在“把房间收拾好”这类整体场景中经常重叠。

再看一组：

There’s sauce on the counter. Please clean it up before it dries.

台面上有酱汁，干掉前把它清理掉。代词放中间：clean it up，不说 clean up it。

The shoes are all over the hallway. Please tidy them up before the guests arrive.

走廊里的鞋到处都是，客人来前把它们整理好。代词同样放中间：tidy them up，不说 tidy up them。

先别看答案，选更贴合表达重点的一项：

1. Coffee spilled across the table. Please ___ before it stains the wood.（clean it up / tidy it up）
2. The desk isn’t dirty, but the papers are everywhere. Please ___ before the video call.（clean it up / tidy it up）

答案和理由在第 5 页。

你家最常需要“收拾”的是哪一处？留一句中文，并说清是去污、清残局，还是把物品归位。
