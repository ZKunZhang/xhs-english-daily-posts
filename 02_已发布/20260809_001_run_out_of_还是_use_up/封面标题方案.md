# 封面标题方案｜run out of / use up

## 路由结果

- 内容赛道：2 自我成长（英语学习）
- 匹配钩子：C 反常识对比、D 如何方法
- 核心观点：中文都表示“用完”，`run out of` 强调已经没有可用之物，`use up` 强调把东西全部消耗掉。

## 方案一｜C 反常识对比 × 对比撕裂型

### 1-1

- 标题：都是“用完”，一个说已经没了，一个说被你耗光
- 第一行：`run out of` ≠ `use up`
- 第二行：一个已经没了
- 第三行：一个全部耗光
- 追溯：C + 2 自我成长，参考案例库 #007

### 1-2

- 标题：牛奶没了，和把牛奶用光，英语不是一个短语
- 第一行：中文都叫用完
- 第二行：一个是结果
- 第三行：一个是动作
- 追溯：C + 2 自我成长，参考案例库 #012

### 1-3

- 标题：run out of 和 use up，差在谁把东西耗光
- 第一行：冰箱已经空了
- 第二行：还是最后一点
- 第三行：被你用掉了
- 追溯：C + 2 自我成长，参考案例库 #010

## 方案二｜D 如何方法 × 结论前置型

### 2-1

- 标题：怎么分清 run out of 和 use up？看你在说结果还是动作
- 第一行：先看重点
- 第二行：没了 `run out of`
- 第三行：耗光 `use up`
- 追溯：D + 2 自我成长，参考案例库 #017

### 2-2

- 标题：一句话分清英语里的两个“用完”
- 第一行：一句话分清
- 第二行：已经没得用
- 第三行：还是全部用掉
- 追溯：D + 2 自我成长，参考案例库 #017

### 2-3

- 标题：说“牛奶用完了”，这两个短语别直接互换
- 第一行：牛奶用完了
- 第二行：先看谁做动作
- 第三行：再选短语
- 追溯：D + 2 自我成长，参考案例库 #017

## Top 3 推荐

1. 方案 1-1：“已经没了 / 全部耗光”把结果与动作直接变成两个可视化场景。
2. 方案 1-2：围绕同一瓶牛奶制造差异，理解成本最低。
3. 方案 2-1：“看结果还是动作”给出了可以立即复用的判断方法。

最终采用方案 1-1。
