## 发布正文

牛奶没了，可以说 `run out of`；把最后一点牛奶也用掉，动作要用 `use up`。

`run out of` = 某人没有某物可用了

`We've run out of milk.`

我们的牛奶用完了。

这句话强调现在没有牛奶可用了。

`use up` = 把某物全部用光

`He used up all the milk.`

他把牛奶全用光了。

这句话强调“他把牛奶消耗掉”这个动作。

一句话记住：

👉 手里已经没了，用 `run out of`。

👉 把剩下的耗光，用 `use up`。

再看两个生活场景：

`We've run out of toilet paper.`

我们的卫生纸用完了。

`She used up the last of the flour.`

她把最后一点面粉用光了。
