# 图片提示词｜run out of / use up

主题：`run out of` 还是 `use up`

## 新版知识卡规范

- 1080 × 1440、竖版 3:4；2:3 输出须用暖奶油白向左右扩展，禁止裁切。
- 封面上下双卡，顺序固定为：大号短语 → 英文释义 → 中文提示 → 加粗英文例句 → 场景插画。
- 封面指定文字：`run out of / 已经没了 / use up / 全部耗光`。定义与例句放到第 2 页，不放封面。
- 英文主导、中文辅助；前者鼠尾草绿，后者杏陶色。不要总标题、`≠`、页码或额外文案。
- 图 2—5 分别承担生活例句、视觉规则、自测、答案。图 4 与图 5 必须复用同一场景和裁切，只改变答案、高亮与勾选。
- 清楚区分“发现已经没有”的结果与“把最后一点用完”的动作；同一厨房和无品牌容器跨页一致。

## 执行方式（必须）

第一步只生成 1080 × 1440、竖版 3:4 的无文字插画底图；牛奶瓶、冰箱、咖啡罐和热水器上不得出现字母、汉字、数字、品牌或包装文字。第二步用固定模板叠加各页“文字”字段。安全区为左右各约 8%、顶部约 7%、底部约 10%；中文一种现代黑体，英文一种无衬线体；最多两种字重；默认左对齐。

5 页固定同一厨房、同款牛奶瓶、同一机位和自然光。只改变“发现时已经空了 / 亲手把最后一点倒完”。左侧是结果状态，右侧是消耗动作；遮住文字仍能判断。禁用粗撕裂、巨大 `≠`、高饱和撞色、夸张表情、3D 塑料感、贴纸和假手写。

补充规范：遵循 `04_模板素材/templates/xhs_visual_system.md`。

统一风格：小红书英语学习笔记，竖版 3:4，延续今天成图验证过的温和生活插画风。暖奶油白背景 `#F7F1E7`；`run out of` 固定使用低饱和鼠尾草绿 `#8FA99A`，`use up` 固定使用柔和杏陶色 `#D7A184`；正文与分隔线使用深咖灰 `#3F3A36`。柔和平涂、水彩晕染和少量纸张颗粒，明亮自然。使用同一间厨房、同一款无品牌牛奶瓶，让两边分别表现“打开冰箱发现已经没有牛奶”和“把最后一点牛奶倒完”。不要高饱和红蓝、纯黑粗撕裂、复杂人物、PPT、贴纸堆叠或密集表格。只出现指定文字，不生成包装品牌、冰箱贴文字或乱码。

统一构图约束：5 页保持同一套字体、纸张纹理、圆角插画框和配色。文字与插画分区，不能互相遮挡。所有英文逐字准确，短语不得缺词或换词。每页只保留一个主要动作，移动端缩略图清晰可读。

## 图 1｜封面

文字：`run out of ≠ use up / 一个已经没了 / 一个全部耗光`

画面：同机位左右对照，冰箱、台面、牛奶瓶外形和光线一致。左侧人物打开冰箱时牛奶位已经空了；右侧人物把同款牛奶瓶的最后一点倒进碗里。中间只留细分隔和小号 `≠`，不用撕裂线。标题与两行动作说明采用固定左对齐网格。

## 图 2｜场景对比

文字：`We've run out of milk. / 我们的牛奶用完了。`；`He used up all the milk. / 他把牛奶全用光了。`

画面：上方为打开冰箱后发现牛奶已经没有；下方为做早餐的人把最后一点牛奶倒进碗里。上下两个圆角插画框，用细深咖灰线分隔，分别高亮 `run out of` 和 `used up`。

## 图 3｜一句话规则

文字：`run out of = 手里已经没了 / use up = 把剩下的耗光 / 没得用 / 全用掉`

画面：左侧用“空冰箱 + 空手”表现结果状态；右侧用“半瓶 → 空瓶”的简洁箭头表现消耗动作。底部独立暖白口诀卡片，只保留指定三行信息。

## 图 4｜自测

文字：`1. We've ___ coffee. / 2. Don't ___ all the hot water. / run out of 还是 use up？`

画面：第一题配空咖啡罐和空杯；第二题配正在长时间放热水的人，热水器余量即将见底。上下两个圆角场景框。不显示答案，不出现勾叉，不在插画中写短语。

## 图 5｜答案复习

文字：`1. We've run out of coffee. / 2. Don't use up all the hot water. / 没得用 / 全用掉`

画面：第一题用鼠尾草绿勾选并配空咖啡罐；第二题用杏陶色勾选并配热水余量下降。底部独立暖白口诀卡片，不添加新解释。

- 画布必须为竖版 3:4，不裁切任何中英文。
- `run out of` 始终为鼠尾草绿，`use up` 始终为杏陶色。
- 左侧强调“发现已经没有”的结果，右侧强调“把最后一点用掉”的动作。
- 第 4 页绝不出现答案、勾号或叉号；第 5 页才显示答案。
