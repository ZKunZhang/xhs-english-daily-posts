# 图片提示词｜put away / throw away

主题：put away 还是 throw away

统一风格：小红书英语学习笔记，竖版 3:4，清爽白色纸张质感，黑色清晰大字，青绿色标记 `put away`，珊瑚红标记 `throw away`。使用衣柜和垃圾桶两个明确生活场景：折好的衣服放进衣柜代表收好，旧物丢进垃圾桶代表扔掉。每页只有一个视觉中心，留白充足，不要 PPT、商务汇报、复杂人物、贴纸堆叠或密集表格。所有英文逐字准确，移动端缩略图清晰可读。

## 图 1｜封面

文字：`put away ≠ throw away / 一个收起来 / 一个直接扔掉`

画面：左右双场景。左侧双手把折好的衣服放进整洁衣柜；右侧双手把旧纸盒丢进垃圾桶。用衣柜和垃圾桶强化完全不同的结果。

## 图 2｜场景对比

文字：`Please put away your clothes. / 请把你的衣服收好。`；`Don't throw away this box. / 别把这个盒子扔掉。`

画面：上方是衣服被整齐收入衣柜；下方是一只手阻止纸盒落入垃圾桶。分别高亮 `put away` 和 `throw away`。

## 图 3｜一句话规则

文字：`put away = 收起来、放回原位 / 东西以后还要用 / throw away = 扔掉、丢弃 / 东西已经不要了`

画面：左侧回转箭头指向衣柜，对应“还要用”；右侧向下箭头指向垃圾桶，对应“不要了”。规则只保留四行。

## 图 4｜自测

文字：`1. Please ___ ___ the toys. / 2. Let's ___ ___ this bag. / put away 还是 throw away？`

画面：两道题上下排列。第一题配玩具收纳箱，第二题配破旧购物袋和垃圾桶。不要显示答案，不要出现勾叉。

## 图 5｜答案复习

文字：`1. Please put away the toys. / 2. Let's throw away this bag. / 还要用就收起来，不要了才扔掉`

画面：第一题用青绿色勾选并配玩具收纳箱，第二题用珊瑚红勾选并配垃圾桶；底部口诀清晰显示。
