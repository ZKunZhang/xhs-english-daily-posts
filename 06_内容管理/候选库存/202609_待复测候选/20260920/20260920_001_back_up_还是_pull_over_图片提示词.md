# 视觉可行性

排期角色：主推“动词短语 + 具体生活场景”池。封面先呈现同一辆车和同一路段，再呈现向车尾倒退 / 向路缘移动并停下两条轨迹和最终车位；遮住文字仍须能判断车辆方向。

同一辆浅色小汽车、同一司机、同一街区俯视机位：back up 的箭头直指车尾，pull over 的箭头斜向路缘并以停车状态结束。遮住文字仍可判断。

# 统一视觉母版

- 版式家族：城市驾驶俯视图 / 两条车辆轨迹。
- 画布与安全区：1080×1440，严格 3:4；左右 8%、顶部 7%、底部 10%。
- 配色：暖奶油白 #F7F1E7，深咖灰 #3F3A36，A 鼠尾草绿 #8FA99A，B 杏陶色 #D7A184。
- 固定主体：同一辆浅色小汽车、司机、石墙、路缘和树影；复古驾驶手册式钢笔线描，局部平涂与旧纸网点；不是水彩，不是 PPT。

# 5 页视觉规划

## Page 01｜封面

严格 3:4 竖版并遵守安全区；统一现代黑体与无衬线体、最多两种字重；无品牌、乱码、霓虹渐变或贴纸堆叠。文字仅为 back up / 往后倒车 / pull over / 靠边停车。两条路线必须方向清晰。

## Page 02｜场景对比

继承汽车、司机与机位。文字：Back up a little. You're too close to the wall. / 往后倒一点，你离墙太近了。 / Please pull over near the entrance. / 请在入口附近靠边停车。

## Page 03｜一句话规则

画面简化为车尾直箭头与斜向路缘箭头。文字：back up = 向后倒 / pull over = 移到路边停下。

## Page 04｜自测

建立车后空位与乘客不舒服两个情境。文字：1. There's a space behind you. ___ slowly. / 2. I feel sick. Could you ___ for a minute? / back up 还是 pull over？不出现答案或提示色。

## Page 05｜答案复习

完全复用第 4 页，只增加答案和轨迹高亮。文字：1. Back up / 2. pull over / 向车后移动 / 向路边移动。
