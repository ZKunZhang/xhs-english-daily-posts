# 发布标题

司机最怕听反的两个指令：back up / pull over

# 封面文案

都是开车动作

back up 往后倒

pull over 靠边停

# 发布正文

停车时听到这两个短语，车走的方向完全不同：一个向后移动，一个向路边移动并停下。

Back up a little. You're too close to the wall.

往后倒一点，你离墙太近了。

Please pull over near the entrance.

请在入口附近靠边停车。

一句话记住：

back up = 让车向后倒

pull over = 把车开到路边停下
