# 发布标题

客人快到了：clean up 还是 tidy up？

# 封面文案

clean up / tidy up

擦掉汤汁

摆齐桌面

# 发布正文

客人快到了，厨房台面上的汤汁要清理，散乱的瓶罐要摆整齐。中文都可以说“收拾一下”，英语常见侧重点不同。

He cleaned up the soup that spilled on the counter.

他清理了洒在台面上的汤汁。重点是去掉污渍和脏乱，所以这里用 clean up。

He tidied up the bottles on the counter.

他把台面上的瓶罐摆整齐了。重点是整理位置、恢复整齐，所以这里用 tidy up。

一句话记住：clean up 常强调清除脏东西或残局；tidy up 常强调把散乱物品整理整齐。日常表达中两者可能重叠，不是绝对分界。

She cleaned up the muddy floor and tidied up the shoes by the door.

她清理了沾泥的地板，又把门边的鞋摆整齐。
