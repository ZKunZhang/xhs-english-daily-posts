# 小红书英语内容工作区

账号定位：生活场景里的高频英语短语强对比。每天发布 1 篇，用同一场景中的动作、方向、位置或结果，讲清一组容易混淆的英语表达。

当前阶段：账号达到 1000 粉后，主线升级为“生活场景选择 + 易混表达解析 + 评论区共创”。粉丝数是结果指标，阶段复盘优先看每千曝光涨粉、有效用户评论率、点击率、收藏率与主页转粉率。当前目标和实际排期见 `03_数据复盘/复盘结论/2026-09_1000粉后增长目标与内容重排.md`。

## 工作流程

执行入口见 [AGENTS.md](AGENTS.md)，文件命名、去重、日期、图片落盘及发布归档统一见 [workflow](04_模板素材/workflow.md)。按请求选择单篇制作、批量策划、外部素材改写、标题编辑或视觉制作，技能与模板索引见 [模板素材](04_模板素材/README.md)。

新稿默认两份文本（发布内容、图片提示词），请求出图时再交付五张成图；只改标题或只做排期时交付对应结果。原始数据与正式复盘入口见 [数据复盘](03_数据复盘/README.md)。

## 内容门槛

- A/B 都是成立且高频的表达。
- 中文意思接近，但英语动作或结果不同。
- 能用一句话讲清，并能用同一场景可视化。
- 优先具体后果型标题；不用考试、课堂或“每日英语”包装。
- 单短语记忆、单点纠错和已充分曝光但承接弱的旧题不进入日更主线。

## 评论互动规范

- 每篇只保留一个主评论动作，在个人选择、用户造句批改、中文场景征集、答案加理由和下期投票中按内容选择。
- 练习题与第 5 页完整答案继续保留；不靠隐藏答案换评论，也不再默认要求用户复制两空答案。
- 自发评论只用于承诺回复范围、征集场景或发起明确投票，不再机械增加一道唯一答案题。
- 评论必须让用户获得个人表达、批改反馈或参与下一篇的真实收益，不用“学会了吗”“你觉得呢”等泛问题。
- 正文结尾说明账号持续价值，并预告下一篇具体场景或表达；避免空泛求关注。
