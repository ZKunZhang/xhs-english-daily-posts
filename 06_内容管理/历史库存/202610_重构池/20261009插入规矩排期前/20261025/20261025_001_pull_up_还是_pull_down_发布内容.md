# 发布标题

都是拉帘子，拉开还是遮住？

# 发布正文

同一扇升降卷帘，朋友说“帮我拉一下”。你是让玻璃露出来，还是把窗户遮住？

Pull up the blind.
把卷帘拉上去。
卷帘收在上方，窗户露出来。

Pull down the blind.
把卷帘拉下来。
卷帘向下展开，把窗户遮住。

一句话记住：看卷帘最后升上去还是降下来，不看手往哪边拉绳子。

再看一组：
I pulled up the blind to let in more light.
我把卷帘拉上去，让更多光线照进来。
She pulled down the blind for some privacy.
她把卷帘拉下来，挡住外面的视线。

这里讲上下升降的 blind，不是左右开合的窗帘。不同机构的拉绳动作可能不同，但这两句话强调的是帘子的升降结果；也可直接用 raise/lower the blind。

先别看答案：
1. 想让光照进来，把卷帘升上去：
A. Pull up the blind.
B. Pull down the blind.
2. 想遮住窗户，把卷帘降下来：
A. Pull up the blind.
B. Pull down the blind.

答案与理由在第5页。请用其中一句给朋友一个清楚的动作指令。

每天一组生活英语，分清用法，也保留能换用的边界。
