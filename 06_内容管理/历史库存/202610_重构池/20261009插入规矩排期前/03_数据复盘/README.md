## 更新规则

1. 在原始数据下建立 YYYY-MM-DD 快照目录。
2. 保留平台原文件；文件名注明指标和导出日期。
3. 每 3 天只调整选题顺序和封面，每 7 天才调整内容比例。
4. 正式分析写入复盘结论，不把分析文档散落到项目根目录或账号定位目录。
5. 具体指标口径见规则/复盘规则.md。
