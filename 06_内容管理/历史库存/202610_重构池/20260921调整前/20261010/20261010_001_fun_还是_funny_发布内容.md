# 发布标题

都是“好玩”：一个玩得开心，一个让人笑

# 封面文案

都是“好玩”

fun  玩得开心

funny  笑出声

# 发布正文

和朋友玩游戏很开心，是 fun；朋友讲了一个笑话让大家笑出来，才是 funny。中文都可能说“好玩”，英语要看是享受，还是发笑。

The game was fun.

这个游戏玩起来很开心。

The joke was funny.

这个笑话把大家逗笑了。

一句话记住：

fun = 有趣、令人享受

funny = 好笑、令人发笑

funny 有时也可以表示“奇怪”，要结合语境。
