# 小红书英语内容工作区

账号定位：生活场景里的高频英语短语强对比。每天发布 1 篇，用同一场景中的动作、方向、位置或结果，讲清一组容易混淆的英语表达。

当前阶段：账号达到 1000 粉后，主线升级为“生活场景选择 + 易混表达解析 + 评论区共创”。粉丝数是结果指标，阶段复盘优先看每千曝光涨粉、有效用户评论率、点击率、收藏率与主页转粉率。当前目标和实际排期见 `03_数据复盘/复盘结论/2026-09_1000粉后增长目标与内容重排.md`。

## 目录

```text
01_内容生产/   当前待发布内容，按发布日期建目录
02_已发布/     历史发布归档
03_数据复盘/   原始数据、复盘结论与规则
04_模板素材/   templates、prompts、skills 与参考资料
05_账号定位/   当前定位与阶段路线
```

## 当前生产规范

01_内容生产通常按计划发布日期建立 `YYYYMMDD/` 子目录，每篇的文本和图片放在对应日期目录内，文件统一命名：

```text
YYYYMMDD_序号_知识点_发布内容.md
YYYYMMDD_序号_知识点_图片提示词.md
YYYYMMDD_序号_知识点_封面.png
YYYYMMDD_序号_知识点_图2_场景对比.png
...
```

日期目录中每篇只要求两份文本：发布内容、图片提示词；成图与两份文本放在同一目录。发布标题直接写在发布内容顶部；不再生成完整发布稿或封面标题方案。英语单词和例句不使用 Markdown 反引号。不在 `01_内容生产/` 根目录散放单篇作品文件。

若阶段重排需要复用既有图片，原日期目录可保留为生产资产编号，实际发布日期由正式排期表接管；不要为了改发布日期批量移动或复制图片。

## 工作流程

1. 查看 05_账号定位/账号定位.md、03_数据复盘/README.md 和最新正式排期。
2. 搜索 01_内容生产、02_已发布和最新数据明细，按知识点去重。
3. 每天发布 1 篇生活场景短语强对比。
4. 图片采用 04_模板素材/templates/xhs_visual_system.md 的固定 3:4 母版。
5. 发布后把整个日期目录归档到 02_已发布，保留目录内的发布内容、图片提示词和最终成图。
6. 新数据按日期保存到 03_数据复盘/原始数据，并按规则复盘。

## 内容门槛

- A/B 都是成立且高频的表达。
- 中文意思接近，但英语动作或结果不同。
- 能用一句话讲清，并能用同一场景可视化。
- 优先具体后果型标题；不用考试、课堂或“每日英语”包装。
- 单短语记忆、单点纠错和已充分曝光但承接弱的旧题不进入日更主线。

## 评论互动规范

- 每篇只保留一个主评论动作，在个人选择、用户造句批改、中文场景征集、答案加理由和下期投票中按内容选择。
- 练习题与第 5 页完整答案继续保留；不靠隐藏答案换评论，也不再默认要求用户复制两空答案。
- 自发评论只用于承诺回复范围、征集场景或发起明确投票，不再机械增加一道唯一答案题。
- 评论必须让用户获得个人表达、批改反馈或参与下一篇的真实收益，不用“学会了吗”“你觉得呢”等泛问题。
- 正文结尾说明账号持续价值，并预告下一篇具体场景或表达；避免空泛求关注。
- 详细模板见 `04_模板素材/templates/xhs_engagement_conversion_template.md`。
