# 小红书英语内容工作区

账号定位：生活场景里的高频英语短语强对比。每天发布 1 篇，用同一场景中的动作、方向、位置或结果，讲清一组容易混淆的英语表达。

## 目录

```text
01_内容生产/   当前待发布内容，按发布日期建目录
02_已发布/     历史发布归档
03_数据复盘/   原始数据、复盘结论与规则
04_模板素材/   templates、prompts、skills 与参考资料
05_账号定位/   当前定位与阶段路线
```

## 当前生产规范

01_内容生产按计划发布日期建立 `YYYYMMDD/` 子目录，每篇的文本和图片放在对应日期目录内，文件统一命名：

```text
YYYYMMDD_序号_知识点_发布内容.md
YYYYMMDD_序号_知识点_图片提示词.md
YYYYMMDD_序号_知识点_封面.png
YYYYMMDD_序号_知识点_图2_场景对比.png
...
```

日期目录中每篇只要求两份文本：发布内容、图片提示词；成图与两份文本放在同一目录。发布标题直接写在发布内容顶部；不再生成完整发布稿或封面标题方案。英语单词和例句不使用 Markdown 反引号。不在 `01_内容生产/` 根目录散放单篇作品文件。

## 工作流程

1. 查看 05_账号定位/账号定位.md 和 03_数据复盘/README.md。
2. 搜索 01_内容生产、02_已发布和最新数据明细，按知识点去重。
3. 每天发布 1 篇生活场景短语强对比。
4. 图片采用 04_模板素材/templates/xhs_visual_system.md 的固定 3:4 母版。
5. 发布后把整个日期目录归档到 02_已发布，保留目录内的发布内容、图片提示词和最终成图。
6. 新数据按日期保存到 03_数据复盘/原始数据，并按规则复盘。

## 内容门槛

- A/B 都是成立且高频的表达。
- 中文意思接近，但英语动作或结果不同。
- 能用一句话讲清，并能用同一场景可视化。
- 优先具体后果型标题；不用考试、课堂或“每日英语”包装。
- 单短语记忆、单点纠错和已充分曝光但承接弱的旧题不进入日更主线。
